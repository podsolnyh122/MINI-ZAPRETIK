# ⚡ MINI-ZAPRETIK

> **Зачем тащить мегабайты лишних файлов, если можно обойти DPI всего в 1.09 МБ?**

**MINI-ZAPRETIK** — это ультра-компактная, портативная сборка на базе ядра `winws.exe` (Zapret) с рабочей стратегией **ALT6** (`multisplit` + `seqovl`). 

Из сборки вычищены все сторонние скрипты, автоапдейтеры, неиспользуемые списки и бинарники. Бинарные файлы пожаты через `UPX --force --best --lzma`, за счёт чего общий вес каталога составляет рекордные **~1.09 МБ**.

---

## 🚀 Особенности

- 📦 **Вес всего ~1.09 МБ** (в оригинальных сборках — от 3.8 МБ и выше).
- 🎯 **Точечная фильтрация:** в отличие от стандартных скриптов, не ломает глобальный трафик, игры и сторонние приложения. Десинхронизация работает строго по доменам из `hostlist.txt`.
- 🛠️ **Проверенная стратегия ALT6:** стабильный обход блокировок и замедлений на YouTube, Discord, SoundCloud и других сервисах.
- 🗂️ **Чистая структура:** всё находится в одном корневом каталоге без вложенных лабиринтов из папок `bin/` и `lists/`.

## 📁 Структура проекта

```text
MINI-ZAPRETIK/
├── winws.exe                           # Сжатое ядро Zapret (~92 КБ)

├── WinDivert.dll                       # Библиотека перехвата пакетов
├── WinDivert64.sys                     # Драйвер ядра WinDivert
├── tls_clienthello_www_google_com.bin  # Шаблон подмены ClientHello (681 байт)
├── hostlist.txt                        # Список доменов для десинхронизации
└── start.bat                           # Лаунчер (с автозапросом прав администратора)
