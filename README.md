# ⚡ MINI-ZAPRETIK

> **Зачем тащить мегабайты лишних файлов, если можно обойти DPI всего в 1.09 МБ?**

**MINI-ZAPRETIK** — это ультра-компактная, портативная сборка на базе ядра `winws.exe` (Zapret) с рабочей стратегией **ALT6** (`multisplit` + `seqovl`). 

Из сборки вычищены все сторонние скрипты, автоапдейтеры, неиспользуемые списки и бинарники.
